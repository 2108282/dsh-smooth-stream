# 正式修复版本记录 — 0.10.4

- 发布分支：main。
- 前一正式版本：0.10.3；本次将 0.10.4-local.3 的已验证功能整理为正常版本 0.10.4。
- 日期：2026-11-23。

## 修复内容

1. 后台追赶不再固定等待至少 40ms；按实际动画回调分配文字预算。
2. Session 重同步完成且积压为空时退出恢复，不等待未来新文字。
3. 收起的思考、工具详情和隐藏祖先不形成不可见的长时间吐字门禁；展开已有内容是完整快照，可见新文字继续动画。
4. 单行 CSS 省略号后不可见的路径尾巴，在已显示前缀实际越过安全裁剪边界后同步，不再逐字拖住后继工具。完整源文本、原点击及 context-menu 事件保持不变。
5. 新源先于 MutationObserver 交付时先接纳新源；同批次的重复 Text 写入只处理最终值一次，并清理开始观察前的初始写入标记，避免原生更新或清空被旧前缀覆盖。

## 不改变的内容与边界

- 16 字追赶预算和用户字速/滚动参数不变。
- context 包装规则、官方组件和交互、Host/client 分离不变。
- 恢复耗时与 FPS 采样只是后续方案，本包没有新增这些诊断。
- rAF 调度与实际屏幕合成帧率不是同一概念；自动化通过不代表初始掉帧已经实机解决。
- 对没有可靠单行几何、RTL/双向文本、复杂独立布局等情况保留原来的动画，不猜测不可见范围。
