# 恢复诊断开始按钮修复 — 0.10.7

- 基于 `0.10.6`，修复插件设置卡中的“开始捕获恢复过程”无响应。
- 16 字追赶上限、字速和滚动参数不变。

## 修复

捕获入口此前受两个无提示门槛阻挡：实时渲染诊断开关关闭时启动函数静默返回；旧 Host 的 `debugAvailable` 标记为 false 时按钮不渲染。现在设置卡完成加载后始终显示独立捕获入口，点击即可启动，并立即切换为“停止并复制恢复诊断”。该状态跨设置卡卸载/重挂继续保持。
