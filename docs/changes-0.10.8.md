# 移除后台文字积压追赶 — 0.10.8

基于 `0.10.7`，当前位于 `fix/remove-background-text-backlog` 分支。

## 变更

- 后台助手文本仅保留最新源快照，不再累计待播放字符、采样字速或启动吐字帧循环；工具文本直接同步已有内容，不加入待播放队列。
- 返回前台时显示已收到的完整助手与工具快照，绕过此前动画形成的接力等待；后续新文字继续正常平滑输出。
- 删除每帧 16 字的恢复追赶预算及恢复积压阈值逻辑；设置页移除三种恢复方式。旧配置值继续兼容读取，统一采用快照同步。
- 修复重连基线与 React 同批提交、同批挂载回复节点、缓存恢复重复消费等时序边界，保留正常前台接力和用户手动展开思考的选择。
- 包版本与诊断导出版本兜底同步为 `0.10.8`，更新预编译产物和安装包。

## 验证

- 功能改动已通过全部 24 个测试文件、452 个测试，类型检查及 Host/Client 构建通过。
- 版本更新重新执行类型检查、测试和构建，并检查安装包内版本与源码、构建产物一致。
- 真实 WebView 前后台切换效果尚未完成实机验证；客户端检查连接曾超时，自动化结果不代表实机视觉验证。
