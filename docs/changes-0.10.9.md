# 后台恢复批次隔离与排序修复 — 0.10.9

- 基于 `0.10.7`，包含 `23cf6f4`（恢复回放批次隔离）和 `54b541f`（空闲输出恢复排序修复）。
- 发布版本号统一为 `0.10.9`，同步设置卡备用版本号、诊断导出备用版本号及预编译安装包。

## 修复内容

- 将后台恢复时已有积压与后续收到的新文本分批播放，避免新文本混入旧批次。
- 修复普通输出与恢复批次互相等待的死锁。
- 修复同一轮仍在恢复时，前序输出空闲或已播完后追加文本重新取得旧批次的问题。
- 根据同一轮的全局回放进度校准接收批次；即使回放已推进到后续批次，新输入仍正确排队。
- DOM 输出在调度入口登记接收批次，暂停播放时也能及时冻结批次。
- 普通重挂载继续遵守前序工具等待；`latest` 回放结束后释放批次标记，恢复普通排序。
