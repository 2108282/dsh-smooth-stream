## 播放行为

- 每个挂载的会话 Flow 共用一个播放队列和字符预算。正文、展开的思考块和工具卡按协议序号接续，不把界面分组顺序误当成协议顺序。
- 支持“正文 A → 工具 → 正文 B”；后继等待前驱明确结束，网络静默或字符暂时耗尽不能代替协议结束标记。
- 工具卡整体放行，保留官方组件的图标、标题、内容和原生操作。启用滚动控制且存在可测量容器时，后继还需等待工具卡入场完成确认。
- 启用对数渐隐且浏览器支持 CSS Highlight 时，前段尾字完成渐隐后才放行后继。折叠内容、静态历史和直接跳到最新的部分不等待该动画。
- 原始流块身份用于保存进度；官方流尝试退休并移交持久化消息时继续已有进度，新尝试则独立播放。
- 初始历史与向前翻页不重播；设置加载期间保留完整原生输出，设置就绪后不重播已经显示的内容。

## 用户设置与后台恢复

继续使用已有速度、物理调参、减少动态效果、滚动控制、思考自动展开、工具调用续播和对数渐隐设置，不更改已保存偏好。

后台期间暂停播放、继续接受数据；恢复前同步已有会话发布，再对一个有限批次应用恢复模式：`replay` 正常续播，`catch-up` 有上限加速追赶且新后缀恢复正常速度，`latest` 跳到该批次最新位置但不越过未结束协议块。

后台恢复会收起插件自动打开的思考区，并暂停本回复再次自动展开；手动选择始终保留，新回复按设置处理。仅自动打开的思考区在播放排空或关闭自动展开设置时自动收起。关闭插件显示完整原生内容，再开启不应隐藏或重播已显示内容。

设置入口为 Web 界面的「设置 → 平滑流式」，亦可通过「设置 → 插件 → 平滑流式」打开同一配置卡。

## 生命周期修复

独立审查发现已挂载 Flow 被 React Suspense 暂时隐藏时，布局 effect 的 cleanup 不能代表永久卸载。本候选版将播放引擎的永久销毁放入 passive effect，以 lifetime generation 和微任务保护 StrictMode 的同步重挂；布局 cleanup 仅使待恢复回调失效。回归覆盖隐藏跨微任务、恢复后复用同一引擎继续播放，以及真正卸载后拒绝新增内容。
