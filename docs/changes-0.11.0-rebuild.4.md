# 0.11.0-rebuild.4：进入基线与后台逻辑移除

本候选在 `0.11.0-rebuild.3` 上继续修订；main 基线仍为 `d0c96a4651e175d393799168c11b42a9a743649a`（0.10.9），不是上游正式 0.11.0。此前 [rebuild.3 说明](changes-0.11.0-rebuild.3.md) 及更早的历史变更记录保留，其后台行为描述不代表本修订的当前规则。

## 进入时已有内容直接显示

主 Flow 在进入会话时读取 Session 来源快照，以源节点和源块身份认领当前已有的正文前缀、思考和工具。已有内容直接显示，随后实时新增内容仍使用统一的协议顺序播放队列。

- 首次进入已有会话，即使回合仍在生成，也不从头重打已有前缀。
- 晚到的历史记录、向前翻页加载的旧内容及重新进入会话时已有的内容直接显示，不重新逐字播放。
- 思考的收起与展开、展示分组变化及渲染器重新挂载，不应把已认领的源前缀重新变成动画积压；新到达的可见思考仍可正常播放。
- 已有工具卡直接显示；实时新增工具继续遵循前序内容与显式协议结束边界，不因为网络静默提前放行。
- 设置加载期间保留 Flow 接管和进入基线，不先切回默认渲染再重新接管。设置就绪后，实时新增内容按实际偏好决定播放资格。

- 已完整显示的动态后继在前序内容重新打开时会重新隐藏，直到前序队列再次完成；仍在播放的前缀和进入基线历史不回退、不重播。此规则覆盖前序追加内容和顺序更早的新子块。

备用 Native 工具渲染路径在可用时共享会话进入基线：首次挂载时已有工具快照直接显示；会话进入后新增的工具内容与其后续 DOM 文本增量仍按原有队列渐显。没有基线来源时保留原有备用渲染行为。共享基线在最后一行卸载后释放，并对闲置会话记录执行上限淘汰。

## 移除后台暂停、恢复模式与恢复协调

插件不再注册专门的后台暂停/前台恢复流程，不再因页面隐藏主动停止吐字、冻结渐显进度或回收并重建跟随几何。原 `replay`、`catch-up`、`latest` 恢复模式、恢复批次及相应协调状态和设置已移除，旧配置中的恢复字段不再作为当前功能。

保留普通逐帧字符预算、播放顺序和滚动动画的长帧限幅。滚动遇到长间隔时，按普通最多 32ms 的动画时间推进，不再进入恢复重定位分支；读者上滑释放、宿主滚动接管与原生输入折叠的让权规则继续保留。渐显按普通时间进度完成，后台事件不再触发出生时间补偿。

实际后台调度仍由浏览器或 Android WebView 控制：它们可能节流或冻结回调。本修订不承诺 WebView 在后台持续执行，也不承诺回到前台必定跳到最新内容或最新滚动位置。保持挂载的 Flow 继续普通播放；真正重新进入会话时重新建立进入基线，已有内容按上述规则直接显示。
