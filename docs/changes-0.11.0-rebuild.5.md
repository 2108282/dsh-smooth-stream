# 0.11.0-rebuild.5：统一可见文本播放并移除淡入

本修订在 `0.11.0-rebuild.4` 的 SessionPlayback 基础上完成插件流式输出重构。核心目标是让一份会话播放队列控制可见文字，不再并行运行淡入动画、旧包装器或独立接力时钟。

## 改动

- 助手回复、工具/上下文/命令/系统提示等原生卡片的可见文字、折叠思考摘要和展开思考正文共享 SessionPlayback 的字符时钟与协议顺序。
- 保留 DSH 原生 renderer、工具详情、按钮和思考展开/收起交互；不在播放适配范围内的节点回退到原生渲染。
- 展开思考的 Body Slot 继续接收未截断的原始文本，但传给可见正文的播放前缀会过滤 `<signature>…</signature>` 元数据；非尾思考块的摘要遵循 DSH 原生块索引规则。
- 删除旧的逐字包装器、旧接力队列和对数淡入实现。历史静态卡片不再安装逐字 DOM 观察器，滚动容器的共享 `transform` 不会触发每张历史卡片重新扫描。
- 设置页标题、描述和启用提示使用中英文 locale 字典，并说明原生卡片与思考摘要/正文的播放范围。

## 兼容范围

- DSH：`>=0.2.3-alpha.2 <0.3.0`
- Node.js：`^24.22.3 || >=26.13.1`

本次范围以当前运行的 DSH `0.2.3-alpha.2` 为基线，不再声明对 `0.2.2-rc.2` 的支持。

- 严格 TypeScript 检查通过。

- 覆盖静态历史卡片观察器、原生卡片文字队列、折叠思考摘要、非尾思考块以及签名元数据过滤的回归用例。
