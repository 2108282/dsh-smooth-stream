# 0.11.0-rebuild.6：卡片文字增量渲染与局部扫描

本修订在 `0.11.0-rebuild.5` 的统一可见文本播放基础上，减少原生卡片播放与内容变化时的重复处理，保留现有共享时钟、协议顺序和原生交互。

## 改动

- 卡片首次挂载时登记文字源；后续未变化的 renderer 提交不重新扫描 DOM。
- SessionPlayback 发布本次发生变化的源 ID，播放帧只更新对应文字节点；宿主文字变化通过局部更新接入共享队列。
- 对新增、替换、移除、移动以及属性变化收敛受影响区域；复用其他文字源和 Unicode 基线元数据。
- 结构变化时同步队列顺序、源身份及隐藏路径，避免前置插入后重新挂载时串用其他文字的播放进度，也避免新内容占用旧隐藏路径后被错误当作历史全文显示。
- 保留隐藏内容与展开操作的原生快照语义，按钮文案立即显示，已完成后继在前序追加或插入内容时重新等待，并在前序完成后恢复已消费进度。
- 修复已完成源移除后局部重新挂载不发布显示状态，以及多个局部扫描之间遗漏宿主同步文字变更的问题。
