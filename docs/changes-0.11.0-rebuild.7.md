# 0.11.0-rebuild.7：播放队列热点优化与共享背压修复

本修订在 `0.11.0-rebuild.6` 的卡片文字增量渲染基础上，减少长历史会话的重复队列扫描，并将跟随引擎的共享背压接回会话播放时钟。

## 改动

- 维护播放队首游标，从最近未完成的段继续播放，避免逐帧重新扫描已完成历史；队列重排或较早来源重新打开时回退游标。
- owner 的成员及顺序未变时跳过全量排序；相同段状态走快速路径，追加文字复用码点数组，重写及拆分代理对边界保留完整重建处理。
- 非活动 owner 更新共享来源时同步回退队首，避免遗漏重新打开的前序内容。
- 将跟随引擎的共享揭示倍率按帧传入 SessionPlayback，无需发布快照或重置播放进度；倍率钳位并保留速度上限。
- 新增 5 项回归测试，覆盖一万段已完成历史后的帧工作量、未变化 owner 的排序跳过、队首重开、共享来源更新及背压倍率。

## 兼容范围

- Node.js：`^24.22.3 || >=26.13.1`

兼容范围与上一候选版一致。
